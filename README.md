# Bangkok MPC — Membership

ระบบสมาชิกชมรมปัญจกีฬากรุงเทพมหานคร (Bangkok Modern Pentathlon Club)

- `index.html` — เว็บทั้งหมดในไฟล์เดียว (static, ไม่ต้อง build) deploy ได้ทันทีบน Netlify / Vercel / GitHub Pages
- `links.html` — หน้ารวมช่องทางโซเชียล (TikTok / Instagram / Facebook) เปิดที่ /links.html
- `supabase/schema.sql` — สำเนา schema ของฐานข้อมูล (เพื่ออ้างอิง ไม่ต้องรันซ้ำบนโปรเจคจริง)

## Stack
- Supabase project **Bangkok MPC** (ref `yrzwbcqargyatagcgiuy`, ap-southeast-1)
- supabase-js + Chart.js (CDN)
- Auth: สมัครด้วย OTP อีเมล → ตั้งรหัสผ่าน → ล็อกอินด้วยอีเมล + รหัสผ่าน

## Roles
- `student` = สมาชิก (ค่าเริ่มต้นตอนสมัคร) — ดูข้อมูลและสถิติของตัวเอง, ดูอันดับชมรม
- `coach` — จัดการสมาชิก, สร้างกิจกรรม (ระบบสร้างรหัสเช็คชื่อ 6 หลักให้), ติ๊กเช็คชื่อแทนสมาชิกได้, บันทึกผลแข่ง

ตั้งโค้ชคนแรกด้วย SQL (หลังสมัครผ่านเว็บแล้ว):

```sql
update public.profiles set role = 'coach'
where id = (select id from auth.users where email = '<อีเมล>');
```

## เช็คชื่อกิจกรรม

- โค้ชสร้างกิจกรรมพร้อมเวลาเริ่ม/จบ → ระบบสร้างรหัส 6 หลักให้อัตโนมัติ (ปุ่ม "รหัส" ในแท็บกิจกรรม, สุ่มใหม่ได้)
- สมาชิกเช็คชื่อด้วยตัวเองในหน้า "ข้อมูลของฉัน" โดยกรอกรหัส ใช้ได้ตั้งแต่ 30 นาทีก่อนเริ่มจนถึงเวลาจบ (เขตเวลา Asia/Bangkok)
- ตรวจรหัสและเวลาฝั่งฐานข้อมูลใน `self_check_in()`; สมาชิกเขียนตาราง attendance ตรงๆ ไม่ได้; กรอกผิดเกิน 5 ครั้งใน 10 นาทีถูกล็อกชั่วคราว
- โค้ชยังติ๊กเพิ่ม/ลบแทนสมาชิกได้เสมอ

## แดชบอร์ดโค้ช

แท็บ "ภาพรวม" (หน้าแรกของโค้ช): จำนวนสมาชิก/สมัครใหม่/กิจกรรมเดือนนี้/เฉลี่ยคนเข้าร่วม, กราฟสมาชิกสะสมและสมัครใหม่รายเดือน, คนเข้าร่วมแต่ละกิจกรรม, สัดส่วนตามรุ่นอายุ, คนเข้ากิจกรรมบ่อยสุด และคนที่ไม่เข้าเกิน 30 วัน (คำนวณฝั่งเบราว์เซอร์จากตารางเดิม ไม่มีตารางเพิ่ม)

## คูปองสมนาคุณ (Redeem)

- โค้ชสร้างคูปองในแท็บ "คูปอง": ชื่อ, รายละเอียด, วันหมดอายุ (ไม่ใส่ = ไม่หมดอายุ), จำนวนสิทธิ์ (ไม่ใส่ = ไม่จำกัด), โค้ด (ไม่ใส่ = สุ่ม 8 ตัว) · ปิด/เปิด, แก้ไข, ลบ, ดูรายชื่อผู้แลกและยกเลิกสิทธิ์รายคนได้
- สมาชิกกรอกโค้ดในแท็บ "คูปอง" แลกได้คนละ 1 ครั้งต่อโค้ด แล้วเห็นใน "คูปองของฉัน"
- ตรวจทุกอย่างใน `redeem_coupon()` ฝั่งฐานข้อมูล; สมาชิกอ่านตารางคูปองได้เฉพาะใบที่ตัวเองแลก; กรอกผิดเกิน 5 ครั้งใน 10 นาทีถูกล็อกชั่วคราว
